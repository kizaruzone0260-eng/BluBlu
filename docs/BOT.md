# Telegram-бот BluBlu (@classblu_bot)

Бот работает по вебхуку на Render (`/webhook/telegram`, секрет в заголовке
`x-telegram-bot-api-secret-token`). Сервис может спать и перезапускаться,
поэтому состояние диалогов живёт в Postgres (`bot_sessions`), а повторная
доставка одного `update_id` не дублирует действия (журнал `bot_updates`).
Тесты бота (`apps/api/test/integration/bot.test.ts`) работают с моком
Telegram API — реальный токен для проверки не нужен.

## Роли

Роль берётся из привязанного аккаунта сайта: `telegram_links → users.role`.
Проверка роли выполняется на сервере для каждой команды и каждого callback;
`callback_data` подписан HMAC и привязан к пользователю (и классу) — подделка
или кнопка из чужого чата даёт вежливый отказ. В группах бот молчит, кроме
привязки группы учителем (`/link <код>`, как раньше).

| Роль | Команды |
|---|---|
| Учитель | /schedule /next /classes /materials /announce /settings /language /help |
| Ученик | /schedule /next /contact /language /stop /help |
| Непривязанный | /start /help /language /schedule (по названию класса) /contact |

Меню команд (`setMyCommands`, scope chat, `language_code` ru/uz/en) ставится
при привязке и снимается при отвязке; при старте сервера обновляется меню
по умолчанию.

## Команды

- **/schedule** — кнопки «Сегодня / Завтра / Неделя» + выбор класса или
  «Все классы»; время в поясе профиля; у каждого пункта кнопка «Открыть».
  Непривязанному бот просит точное название класса и показывает расписание
  только если у класса включён переключатель **«Расписание через
  Telegram-бота»** (настройки класса; по умолчанию выключен). Ответ — только
  время и название, без ссылок, описаний и материалов. Неверное название и
  закрытый класс отвечают одинаково. Лимит подбора по названию — 10/мин.
- **/next** — ближайшее событие; у учителя кнопка «Начать урок», у ученика —
  «Открыть».
- **/classes** (учитель) — классы с числом учеников и кнопками «Открыть класс».
- **/materials** (учитель) — последние 5 материалов выбранного класса.
- **/announce** (учитель) — выбор класса кнопками или быстрая форма
  `/announce <точное название> <текст>`; затем текст (≤2000); затем
  предпросмотр с кнопками «Отправить»/«Отмена». Подтверждение действует
  10 минут; без него ничего не отправляется, повторное нажатие не создаёт
  дубль. После отправки: объявление в классе, уведомление ученикам через
  pg-boss (дедупликация), запись в audit_log.
- **/settings** (учитель) — переключатели напоминаний (24 ч / 1 ч / 10 мин,
  «урок начался», «новый материал»), тихие часы (только для напоминаний),
  список заблокированных и «Разблокировать».
- **/contact** — три шага: имя и фамилия (2–80) → класс (≤40; привязанному
  ученику предлагаются кнопки его классов) → текст (≤1000). Диалог истекает
  через 15 минут, `/cancel` отменяет. Учитель получает один отчёт; кнопки под
  ним: «Ответить» (бот перешлёт текст ученику с пометкой «Ответ учителя»;
  связь отчёт↔чат хранится 30 дней) и «Заблокировать отправителя».
  Ограничения: 3 обращения в час, заблокированные не пишут. Введённый текст
  экранируется и никогда не разбирается как HTML.
- **/language** — ru / uz / en (синхронно с профилем сайта).
- **/stop** — отвязка и отключение уведомлений.
- Напоминания и «урок начался» с кнопкой «Войти в урок» продолжают приходить
  по настройкам (`notification_prefs`).

## Примеры текстов

Ученик без привязки, закрытый класс (и выключенный переключатель, и неверное
название — один и тот же ответ):

    Класс не найден или расписание не открыто.

Открытый класс (`bot_public_schedule` включён):

    PUB1759657392
    • 06/10 15:00 — Открытый урок

Предпросмотр объявления:

    Класс «7Q 1759657392245» (1 учеников): Завтра контрольная <b>тест</b>
    [ Отправить ]  [ Отмена ]

Отчёт учителю от /contact (непривязанный отправитель):

    Новое обращение через бота.
    Имя: Аноним Вопросов
    Класс: 7Q
    Сообщение: Здравствуйте! &lt;script&gt;alert(1)&lt;/script&gt;
    Время: 05/10/2026, 15:42 UTC
    [ Ответить ]  [ Заблокировать отправителя ]

То же от привязанного ученика (строка аккаунта добавляется автоматически):

    Аккаунт: Сидор Сидоров, классы: 7Q 1759657392245 (подтверждено)

Ответ учителя ученику:

    Ответ учителя: Урок в четверг, всё будет.

## Технические детали

- `bot_sessions` (chat id, state, data jsonb, expires_at) — диалоги
  announce/contact/reply; `sweepBotState` чистит истёкшие каждые 10 минут.
- `bot_updates` — журнал `update_id` (идемпотентность вебхука).
- `contact_reports` — отчёты; ссылка отчёт↔чат живёт 30 дней.
- `contact_blocklist` — блокировки по инициативе учителя.
- `classes.bot_public_schedule` — переключатель публичного расписания.
- Все новые таблицы: RLS включён, `anon`/`authenticated` отозваны (миграция
  0013).
- Лимиты: ≤20 команд/мин на пользователя; ответы на команды не подчиняются
  тихим часам (только напоминания).

## Как проверить

1. Тесты без токена: `pnpm --filter @klass/api test:integration`
   (файл `test/integration/bot.test.ts`, мок CapturingApi).
2. Живой бот: в `cloud.env`/Render задать `TELEGRAM_BOT_TOKEN`,
   `TELEGRAM_BOT_NAME=classblu_bot`, `TELEGRAM_WEBHOOK_SECRET`,
   `TELEGRAM_TRANSPORT=telegram`, `PUBLIC_URL`; после деплоя бот сам
   регистрирует вебхук (`setWebhook`) и меню по умолчанию.
3. В интерфейсе: профиль → Telegram → «Подключить» → открыть ссылку →
   /start выполнит привязку и выдаст меню роли. Переключатель расписания —
   Класс → Настройки → «Расписание через Telegram-бота».
