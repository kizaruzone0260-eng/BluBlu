# Демо BluBlu без собственного сервера

Цель: показать платформу клиенту прямо с вашего компьютера — сайт наружу через
Cloudflare Tunnel, видео через LiveKit Cloud. Это **демонстрационный режим**;
боевой self-hosted режим (docs/DEPLOY.md) не меняется.

## Что нужно один раз установить

### 1. cloudflared (бесплатно, Apache-2.0)

Windows, без админ-прав и без аккаунта Cloudflare:

```powershell
winget install --id Cloudflare.cloudflared -e
```

(проверено на этой машине: MSI кладёт бинарник в
`C:\Program Files (x86)\cloudflared` — после установки откройте новое окно
терминала, чтобы PATH обновился)

Если winget недоступен — скачайте `cloudflared-windows-amd64.exe` со
страницы релизов https://github.com/cloudflare/cloudflared/releases,
переименуйте в `cloudflared.exe` и положите каталог с ним в `PATH`
(например, `%LOCALAPPDATA%\Programs\cloudflared`). Проверка:

```powershell
cloudflared --version
```

Быстрый туннель (`--url`) не требует аккаунта Cloudflare и выдаёт одноразовый
адрес вида `https://случайные-слова.trycloudflare.com`. **Адрес меняется при
каждом запуске** — это нормально для демо.

### 2. Зависимости проекта

```bash
pnpm install
```

### 3. .env

Скопируйте `.env.example` → `.env` (файл `.env` в `.gitignore`, коммитить его
нельзя) и заполните блок LiveKit Cloud:

```ini
LIVEKIT_URL=wss://ваш-проект.livekit.cloud
LIVEKIT_API_KEY=API…            # из консоли https://cloud.livekit.io
LIVEKIT_API_SECRET=…            # там же
TELEGRAM_MODE=polling           # демо: бот сам забирает сообщения, webhook не нужен
TELEGRAM_TRANSPORT=telegram     # или log, если бота показывать не надо
TELEGRAM_BOT_TOKEN=…            # токен от @BotFather (для демо не обязателен)
```

`LIVEKIT_URL` перекрывает self-hosted `LIVEKIT_WS_URL`/`LIVEKIT_INTERNAL_URL`:
клиент получает адрес облачного LiveKit **от API** (в ответе join и по WS
статуса), а серверные вызовы RoomService идут в `https://…livekit.cloud`.
Продакшн-режим (Caddy + `/rtc`) остаётся рабочим: просто оставьте
`LIVEKIT_URL` пустым.

## Запуск демо

Одна команда из корня репозитория:

```bash
pnpm demo
```

Она поднимает: embedded PostgreSQL (порт 5434, данные в `apps/api/.pgdata-demo`),
API с уже собранным веб-бандлом (тот же адрес, что и API; соберётся сам при
первом запуске), Cloudflare-туннель, и сеет демо-данные. В консоли появится
большой баннер с публичным адресом и доступами. `Ctrl+C` — остановить всё.

Полезные флаги: `pnpm demo -- --rebuild` (пересобрать веб),
`pnpm demo -- --no-tunnel` (только localhost, без облачного адреса).

## Демо-доступ и сценарий показа

Один сид-аккаунт (пустая база — всё остальное создаёте вживую):

| Роль | Логин | Пароль |
|---|---|---|
| Учитель | `teacher@demo.klass.local` | `DemoTeacher123` |

Свежий запуск каждый раз печатает эти же доступы в баннере.

1. **Учитель (ваш браузер):** «Создать класс» → «+ Событие» в календаре (можно
   еженедельное) → «Создать код» приглашения (одноразовый, показывается один раз) →
   заметки («Добавить заметку» — в любой момент, с закреплением и привязкой к уроку) →
   «Начать урок».
2. **Ученик (другое устройство):** тот же адрес туннеля → «Присоединиться к классу» →
   регистрация (имя, e-mail, пароль ≥8) → код из п.1. Видит: ленту, календарь, свой
   приватный листок, вход в урок, доску только на чтение.

Всё, что создано на демо, редактируется и удаляется в интерфейсе (класс — настройки/архив,
события — правка/удаление/перетаскивание, материалы/объявления/заметки — до записи).

## Проверка (автоматическая)

Пока демо запущено, в другом окне:

```bash
pnpm demo:check -- --base https://ВАШ-trycloudflare-адрес --livekit wss://ВАШ.livekit.cloud
```

Скрипт строит **собственные фикстуры через API** (класс → одноразовый код → ученик →
урок → заметка) и убирает за собой (завершает урок, архивирует класс). Сквозь туннель
проверяются: HTTP, входы, выдача токена LiveKit (wsUrl = адрес из `.env`, гранты
`roomAdmin`/«камера+микрофон»), заметка вне класса и закрепление, WS статуса урока и
WS доски, одноразовость билетов (4401). Сам видеозвонок между двумя людьми проверяется
вручную: начните урок под учителем и подключитесь учеником.

## Чем демо отличается от продакшна

| | Демо | Продакшн (docs/DEPLOY.md) |
|---|---|---|
| LiveKit | облако LiveKit Cloud (LIVEKIT_URL) | self-hosted контейнер, медиа через Caddy `/rtc` + TURN |
| HTTPS/адрес | одноразовый `*.trycloudflare.com` | домен + Let's Encrypt (Caddy) |
| База | embedded-postgres на вашем ПК | PostgreSQL в Docker, регулярные бэкапы |
| Telegram | long-polling (`TELEGRAM_MODE=polling`) | webhook + секрет (`TELEGRAM_MODE=webhook`) |
| Caddy | не используется | reverse-proxy + TLS + логи с redact |
| Логи | stdout | pino/Caddy, query-параметры вырезаются |

## Ограничения LiveKit Cloud

Бесплатный тариф **Build: 5000 participant-minutes в месяц** — например, урок
на 4 участника по 60 минут = 240 минут. После исчерпания лимита видео
останавливается (аудио-трафик тоже), остальные функции демо продолжают работать.
Лимит считается календарно; детали — https://livekit.com/pricing.

Quick Tunnel Cloudflare бесплатен, но не подходит для продакшна: адрес меняется
при каждом запуске, пропускная способность и стабильность не гарантируются.
