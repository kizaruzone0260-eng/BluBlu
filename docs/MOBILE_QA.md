# Проверка на телефоне

Два слоя: автоматический обход экранов (`apps/e2e/tests/m-phone-screens.spec.ts`, проект
`pixel7` в Playwright: Chromium, 393×851, `isMobile` + `hasTouch`) и этот чеклист для настоящих
устройств. Эмуляция не заменяет чеклист: она не знает про клавиатуру, безопасные зоны,
автоповорот, `getDisplayMedia` в Safari и реальную задержку сети.

## Чего эмуляция не проверяет вовсе

- ** Настоящая экранная клавиатура**: сдвиг вьюпорта, `resize`, потерю фокуса, автокоррекцию.
- **Safe areas** на устройствах с «чёлкой»: `env(safe-area-inset-*)` в CSS есть, но значение
  появляется только на реальном экране.
- **`getDisplayMedia`** в iOS Safari (отсутствует) и выбор окна в Android Chrome — на десктопной
  эмуляции есть всегда.
- **`setSinkId`** — отсутствует и там, и там; проверяется только что код не падает.
- **Full Screen API** для элемента в iOS: поддерживает только `video`, поэтому у урока там
  ожидается объясняющая строка, а не кнопка.
- **Фактические звук и картинка** в уроке: фейковые устройства в тестах не доказывают, что
  собеседника слышно. Только живой двухсторонний звонок.
- **Слабый сигнал, поворот экрана, блокировка телефона, свернуть/вернуть вкладку** — всё
  ручное.
- **Производительность на реальном железе**: у этой машины 7.6 ГБ, она не является образцом.

## Как запустить автоматическую часть

```
pnpm -r build
pnpm --filter @klass/e2e exec playwright test --project=pixel7
```

Проект требует Chromium (`playwright install chromium`); на машине разработчика браузер
не скачивается, поэтому мобильный набор исполняется только в CI.
