## Этап 1 — основа (ГОТОВ, тесты зелёные)

Сделано: монорепозиторий (pnpm workspaces), схемы БД + миграция 0000, аккаунты (argon2id,
JWT 15 мин + refresh httpOnly SameSite=Lax с ротацией и обрывом family при переиспользовании,
seed-учитель), классы (CRUD/архив/участники/перенос), одноразовые коды (8 символов без
0/O/1/I/L, SHA-256+pepper в БД, показ один раз, TTL 1–30 дней, атомарный redeem
`UPDATE … WHERE used_at IS NULL AND revoked_at IS NULL AND expires_at > now() RETURNING`,
блок 15 мин после 5 попыток, одинаковая ошибка invalidCode), web-UI (login, регистрация по
коду, классы, панель кодов, участники, профиль), i18n ru/uz.

## Этап 2 — материалы, объявления, файлы, заметки (ГОТОВ, тесты зелёные)

Сделано: лента (pinned первыми, темы), материалы с файлами (multipart, magic-bytes по
разделу 3.3, PDF/PK+OOXML/png/jpg/gif/webp/tiff/bmp/ID3-mp3/ftyp-mp4/m4a/txt; исполняемое
под маской .pdf отвергается), лимит 100 МБ (в тестах 2 МБ) → 413, квота учителя 5 ГБ → 507,
хранение за StorageProvider (диск, ключ UUID), скачивание только через авторизованный
эндпоинт с проверкой членства (чужой = 404), inline-предпросмотр pdf/картинок/аудио/видео
(SVG запрещён как вектор XSS), HTTP Range → 206, nosniff; заметки учителя на Tiptap (MIT)
с debounce-автосейвом 800 мс и публикацией в ленту (повторная публикация обновляет тот же
post); удаление поста чистит файлы с диска. UI: блок ленты в классе, формы материала/
объявления, пин/удаление, preview-модалка, страница /notes, локали ru/uz для всех новых
строк.

Ключевые тесты: чужой ученик за файлом → 404; exe-под-.pdf → 415; Range 0-99 → 206 c

## Этап 3 — календарь (ГОТОВ, тесты зелёные)

Сделано: события (урок/дедлайн/другое) с хранением UTC+IANA; повторы «еженедельно по
дням до даты» — RRULE итерируется в pseudo-UTC (wall-clock) пространстве и переводится в
реальные моменты через Intl-функцию (19:00 по Ташкенту остаётся 19:00 в этой зоне после
перехода летнего времени — тест на America/New_York через дату DST 08.03.2026);
редактирование/удаление со scope «только это» (EXDATE + одиночная замена), «это и
следующие» (UNTIL старой серии + новая), «все»; лента «мои события» для ученика со
всеми классами и фильтром; ICS-подписка: персональный секретьный токен (в БД только
SHA-256), отдача text/calendar с DTSTART в UTC; UI: FullCalendar (месяц/неделя/список),
форма события с днями недели и до-датой, панель scope при правке повтор-события, кнопка
получения ICS-ссылки в профиле. Права: чужой учитель не видит и не правит события (тест
поймал дыру без teacherId-фильтра — исправлено).

Проверено (`pnpm --filter @klass/api test:integration`):


утром; формат стандартный RFC 5545, UTC-формы).
